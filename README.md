# destroy your jpg (jpg.my.id)

Aesthetic minimal in-browser JPEG cruncher & artifact generator.

100% client-side (Vanilla HTML5 Canvas & CSS), zero server uploads, completely private and instant.

## Features
- **Extreme JPEG Quality**: Quality slider ranging from 1% to 100%.
- **Compression Passes**: Multi-pass lossy compression (1x to 12x) to simulate images re-uploaded hundreds of times across the internet.
- **Pixel Crunch (Downscale)**: Resample down and back up to produce genuine DCT 8x8 block artifacts.
- **Deep Fried Mode 🔥**: Toggle for heavy contrast and saturation boosting.
- **Instant Preview & Compare**: Hold to compare with the original uncompressed image.
- **Flexible Input**: Drag & Drop, file picker, or direct **Clipboard Paste (`Ctrl + V`)**.
- **Actions**: Download `.jpg` or copy image directly to clipboard.
- **Default Sample**: Built-in Mr. Krabs meme (*"MANA CELANANYA?"*).
- **Ultra-minimalist White Theme**: Clean single-page layout with pure `#ffffff` background, Plus Jakarta Sans typography, and powered by movianlife.
